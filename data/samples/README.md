# data/samples

Small, curated, **non-sensitive** sample datasets for development, tests, and demos. Everything else under `data/` is gitignored.

## `sales_history.csv`

Synthetic kirana/D2C sales history, deterministically generated by
[`scripts/generate_sample_sales.py`](../../scripts/generate_sample_sales.py)
(stdlib only — no numpy/pandas needed). Regenerate with:

```bash
python scripts/generate_sample_sales.py --out data/samples/sales_history.csv \
    --start 2024-01-01 --days 730 --seed 42
```

**Shape:** 2 stores × 8 SKUs × 730 daily rows = 11,680 rows (~560 KB).

### Columns (canonical sales-history schema)

| Column | Type | Notes |
|---|---|---|
| `date` | ISO date | daily granularity |
| `store_id` | string | `STORE-DEL-01`, `STORE-BLR-02` |
| `sku_id` | string | product identifier |
| `units_sold` | int ≥ 0 | zeros are real (no demand / stockout) |
| `price` | decimal | unit price (currency-agnostic) |
| `promo_flag` | 0/1 | promotion active that day |

### Demand patterns covered (ADI / CV² quadrants)

The eight SKUs deliberately span all four intermittent-demand quadrants so the
forecasting ladder (naive → classical → Croston/SBA/TSB → LightGBM) can be
exercised and compared honestly. Verified classification:

| SKU | Pattern | ADI | CV² | zeros |
|---|---|---|---|---|
| SKU-MILK-1L | smooth | 1.02 | 0.17 | 1.5% |
| SKU-BREAD-400 | smooth | 1.03 | 0.23 | 3.3% |
| SKU-RICE-5KG | erratic | 1.12 | 0.89 | 10.6% |
| SKU-OIL-1L | erratic | 1.22 | 1.19 | 17.8% |
| SKU-SHAMPOO-S | intermittent | 2.39 | 0.45 | 58.2% |
| SKU-BATTERY-AA | intermittent | 3.44 | 0.47 | 71.0% |
| SKU-PRESSURE-CK | lumpy | 10.43 | 2.16 | 90.4% |
| SKU-GIFT-BOX | lumpy | 13.77 | 2.16 | 92.7% |

> Quadrant rule (Syntetos-Boylan): `smooth` ADI<1.32 & CV²<0.49; `erratic` ADI<1.32 & CV²≥0.49; `intermittent` ADI≥1.32 & CV²<0.49; `lumpy` ADI≥1.32 & CV²≥0.49.

### Built-in signal (so models have something to learn)

Weekly seasonality (weekend lift), annual seasonality, multiplicative trend,
Indian-festival spikes (Diwali/Holi/Raksha Bandhan), promo lift, per-store
scaling, and occasional multi-day stockout zero-runs. All seeded → reproducible.
